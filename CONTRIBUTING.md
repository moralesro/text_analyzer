# Cómo contribuir

Abre un issue con el problema o mejora. Crea una rama `feature/descripcion` o
`fix/descripcion`. Mantén cada PR enfocado y agrega pruebas del comportamiento.
Ejecuta las tres validaciones del README antes de enviar cambios.

Abre un Pull Request hacia `main`, explica qué cambia y vincula el issue.
Un colaborador puede revisar el PR y dejar observaciones. Responde con nuevos
commits en la misma rama. Fusiona solamente cuando `quality` pase.
No subas credenciales, el entorno virtual ni los reportes de cobertura.
